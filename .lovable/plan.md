## Milestone 1: Project Foundation — Janat Sahara Travel

Setting up scaffolding only. No pages, no business features yet.

### 1. Backend / Environment
- Enable **Lovable Cloud** (Supabase under the hood) so auth + DB are ready for later milestones.
- Confirm env variables wired: `VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY` (client) and `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY`, `SUPABASE_SERVICE_ROLE_KEY` (server).
- Keep Supabase client in `src/integrations/supabase/client.ts` (auto-generated by Cloud).

### 2. Design System (`src/styles.css`)
Premium Arabic/travel identity based on the uploaded brand:
- **Palette (oklch tokens, light + dark):**
  - Primary: warm orange `#E8722C` (from logo/balloon)
  - Secondary/Accent: deep green `#0F3D2E` (dark footer in mockup)
  - Sand/cream neutrals, gold highlight
  - Full shadcn semantic tokens (background, foreground, card, muted, border, ring, sidebar, destructive, chart-1..5) in `:root` and `.dark`
- **Gradients & shadows:** `--gradient-hero`, `--gradient-primary`, `--shadow-elegant`, `--shadow-card`
- **Typography:** Cairo / Tajawal (Arabic) + Inter (Latin) loaded via `<link>` in `__root.tsx`; registered as `--font-display`, `--font-body` in `@theme`
- **Radii + motion tokens**

### 3. RTL & i18n
- Add `dir="rtl"` and `lang="ar"` on `<html>` in `__root.tsx` (RTL-first).
- Install `i18next` + `react-i18next`. Config in `src/lib/i18n.ts`.
- Locales in `src/locales/ar/common.json` (default) and `src/locales/fr/common.json`.
- `LanguageProvider` toggles `dir` + `lang` on `<html>` when switching AR ⇄ FR.

### 4. Theme (dark/light)
- `src/components/theme-provider.tsx` — class-based, persists to `localStorage`, respects system preference.
- `src/components/theme-toggle.tsx` — icon button in navbar.

### 5. Global Layout
- `src/components/layout/Navbar.tsx` — sticky, logo (uploaded `logo_pdp.png` via lovable-assets), nav links placeholders, language switcher, theme toggle, "Book now" CTA, mobile drawer.
- `src/components/layout/Footer.tsx` — brand block, quick links, contact info, socials, dark green background matching mockup.
- `src/components/layout/SiteLayout.tsx` — wraps `<Outlet />` with Navbar + Footer.
- Applied in `src/routes/__root.tsx` around `<Outlet />`.
